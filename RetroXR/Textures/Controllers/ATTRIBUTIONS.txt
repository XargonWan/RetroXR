Controller art — attribution
============================

Art in this directory feeds the CONTROLS tab's remap diagrams. Four sources,
each redistributable and none carrying anyone's branding.


quest_touch_plus_left.png / quest_touch_plus_right.png
------------------------------------------------------
  Baked by Tools/bake_controller_art.py from the meta-quest-touch-plus glTF.

  Source   : https://github.com/immersive-web/webxr-input-profiles
  Licence  : MIT
  Note     : white RGB with the drawing in the alpha channel, so the diagram
             tints it with modulate. Meta's own controller art is NOT
             redistributable and is deliberately absent from this repo.


gamepad_line.svg
----------------
  Our own work, drawn by Tools/gen_gamepad_art.py. An Xbox *layout* — offset
  sticks, ABXY diamond, bumpers and triggers — and deliberately not an Xbox:
  no logo, nothing traced, so there is no mark being borrowed.

  Licence  : same as this project.

  THIS IS THE ONLY SHARE-ALIKE ASSET IN THE REPO. Two obligations follow, and
  neither is optional:

    1. ATTRIBUTION. Credit the author and name the licence wherever the game is
       distributed. Done in the ARTWORK section of the in-app About panel

    2. SHARE-ALIKE. This file is a DERIVATIVE (see below), so the modified file
       is itself CC BY-SA 3.0 and must stay so. It does NOT relicense the rest
       of the project: an asset shipped alongside the code is not a combined
       work with it, and every other file keeps its own terms. Do not paste
       parts of this drawing into art that is meant to be ours.

  Modified : the "Nintendo(R)" wordmark was REMOVED — eleven #FE0016 paths,
             ids path6991/6995/6999/7003/7007/7011/7015/7019/7023/7027/7029,
             which together drew the eight letters and the registered-trademark
             mark in the top right of the face. Nothing else was touched: no
             other path, no colour, no transform, and the viewBox is upstream's
             own ("-0.004 270.034 612.002 251.924"), already tight to the pad.
             Removing a trademark is a trade-dress measure, not a licence one;
             CC BY-SA permits the modification either way.

  Branding : none remains. The SELECT / START legends and the B / A button
             letters are kept — those are functional labels naming the controls
             the diagram binds, not anyone's mark.

  Anchors  : measured from a Godot render by Tools/nes_pad_anchors.py and stored
             in Scripts/Data/systems/console_pad_art.gd. Re-run that tool if this
             file is ever replaced.


wii_remote.svg
--------------
  COMPOSED by Tools/gen_wii_remote_art.py from two CC0 sources. Re-run that
  script rather than editing this file; it also prints the anchors.

  the shell : MilkToastRat Pack, SVG/wii.svg
              https://github.com/milktoastrat/milktoastrat-pack
              Licence : CC0-1.0 (LICENSE file in that repo)

  the marks : Kenney, "Input Prompts" 1.5, Nintendo Wii/Vector/wii_button_*.svg
              https://kenney.nl/assets/input-prompts
              Licence : CC0-1.0 (stated on the asset page and in the download)

  Modified : the shell arrives with BLANK buttons, which is no use in a remap
             diagram where a row called "minus" has to be matched to a physical
             cap. The six marks the hardware carries — A, minus, home, plus, 1,
             2 — are lifted out of Kenney's glyphs and printed onto it, each
             scaled by its own cap so it keeps the proportion Kenney drew it at,
             and inked in #3d3d3d, the grey the shell already uses for its
             speaker holes. Kenney's white would be invisible on a white remote.
             The viewBox is cropped from the source's 1000 square to the drawing's
             own extent; uncropped, three quarters of the diagram is empty.

  Why these : both are CC0, so neither adds a second share-alike obligation
             alongside nes_pad_colour.svg. Taking the marks from the same Kenney
             family the diagrams already use for their legend chips also means
             the mark on the picture and the chip beside it are one drawing
             rather than two artists' idea of a plus sign.

  Branding : none. The marks are the functional labels naming the controls the
             diagram binds; there is no wordmark on the shell and none was added.
